
# 💸 Expense Manager

A simple and efficient Android application built with **Kotlin** and **Jetpack Compose** to help users track their expenses and manage their daily finances with ease.

![Android](https://img.shields.io/badge/platform-Android-green?logo=android)
![Kotlin](https://img.shields.io/badge/language-Kotlin-purple?logo=kotlin)
![Jetpack Compose](https://img.shields.io/badge/UI-Jetpack%20Compose-blue)

---

## ✨ Features

* 📊 **Add, View & Manage Expenses**
  Record your expenses with category, amount, and date.

* 📅 **Date-wise Expense Tracking**
  Easily view your spending history by date.

* 📁 **Category-based Spending Summary**
  Analyze where your money is going using categories.

* 🧾 **Expense List View**
  All your entries in one scrollable list.

* 🎨 **Modern UI with Jetpack Compose**
  Smooth and responsive interface using the latest Android UI toolkit.

## 🚀 Getting Started

### Prerequisites

* Android Studio Flamingo or later
* Gradle 8.0+
* Kotlin 1.8+
* Android SDK 33+

### Clone the Repository

```bash
git clone https://github.com/rishu8090/Expense-Manager.git
cd Expense-Manager
```

### Run the App

1. Open project in **Android Studio**
2. Sync Gradle
3. Run on an emulator or physical device
